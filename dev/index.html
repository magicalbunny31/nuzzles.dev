flooded area bot and flooded area moderation

app developer for flooded area community

  • flooded area bot is a discord app which brings new features to the flooded area community!
  • features the flooded area bot app brings to the server includes:
    • a thread-based system for the flooded area game suggestions
    • a tickets system, for handling: player reports, ban appeals, and mod mail for flooded area and the flooded area community
    • "fun" features to keep the community engaged, through: commands, levels, or other means such as question of the day
    • interactive ways for viewing game information: condensing and ordering text using interaction components or setting them out nicer using colourful embeds
  • flooded area moderation is a discord app which allows for flooded area moderation to take place from the flooded area community
  • features flooded area moderation app brings to the server includes:
    • a feature-rich way for the flooded area staff to (mass-)moderate players straight from the discord server without needing to join in-game, through the roblox open cloud api
    • providing the flooded area staff an easy to look-up moderation history of a flooded area player by monitoring the moderation's logging channel
