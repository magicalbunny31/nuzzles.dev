an app representing the friends' smp

Overview

friends' smp (code name "friends-smp-app") is an app for my invite-only survival multiplayer minecraft server: open to my friend group!

❓ what does friends' smp app do?

  • the ability to view general information about the minecraft server from the minecraft server's related discord community
  • have commands for quick links to each command's respective resources
  • trivial and fun commands to build community rapport seriously? that's incredibly mawkish..
  • providing private (pre-signed) download links (to those within the minecraft server's related discord community) to the backups of the server (of which the backup files are published via friends-smp-backups)

🗃️ the friends' smp universe is quite large

    there's a lot of tools that make up friends' smp!
    • friends-smp: the minecraft server itself, running on papermc
    • friends-smp-map: a web-based map of the server running bluemap, running on cloudflare workers with cloudflare r2 bindings
    • friends-smp-status: a monitoring tool for the server's resources using uptime kuma
    • friends-smp-backups: a simple cron-scheduled python backup script for the minecraft server and friends-smp-map
    • friends-smp-worlds: wiki pages, hosted using an otter wiki, providing information about the backup files published via friends-smp-backups and hosting lore and screenshots of the past worlds of friends' smp
    • friends-smp-app: a discord app based on interactions via http-based outgoing webhooks running on cloudflare workers
      • this app is (and always has been) my first app using interactions via http-based outgoing webhooks!
