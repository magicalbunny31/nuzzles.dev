Overview

aviflight558 was an app that provided information about aviation, made for @aviation558_

📋 aviflight558's commands

  • /aircraft aircraft-registration
    • view information about an aircraft with the registration aircraft-registration
  • /airport airport-code
    • view information about an airport with the code airport-code
  • /fact
    • ..it gets some random aviation fact wowie
  • /flight callsign
    • view information about a flight with the call sign callsign
  • /nearby area
    • view information of nearby aircraft given the area's airport
  • /plane
    • view a random plane image !!
